JihoCalculator

1. 프로그램 소개

JihoCalculator는 C++로 제작한 다기능 계산기를 웹브라우저에서도 사용할 수 있도록 발전시킨 프로그램입니다.

생성형 AI인 ChatGPT를 활용하여 HTML, CSS, JavaScript로 웹 계산기를 구현하였으며, PC와 스마트폰에서 사용할 수 있도록 제작하였습니다.

2. 주요 기능

덧셈, 뺄셈, 곱셈, 나눗셈

거듭제곱, 제곱근, 백분율 계산

계산 기록 조회 및 초기화

계산 기록 TXT 파일 다운로드

이전 계산 결과 재사용

잘못된 계산에 대한 오류 메시지 표시

브라우저에 계산 기록 자동 저장


3. 사용 방법

1번째 : 아래 웹사이트 주소에 접속합니다.

2번째 : 계산 종류를 선택합니다.

3번째 : 계산할 숫자를 입력합니다.

4번째 : '계산하기' 버튼을 누릅니다.

6번째 계산 결과와 계산 기록을 확인합니다.


4. 개발 과정

1주차: Visual Studio에서 C++ 콘솔 계산기 제작

2주차: HTML, CSS, JavaScript를 이용한 웹 계산기 구현

3주차: GitHub Pages를 이용한 웹사이트 배포 및 스마트폰 실행 확인
